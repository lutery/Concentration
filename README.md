# QQ 连连看外挂程序

这是一个用于 QQ 游戏连连看的自动消除工具。程序读取游戏进程内存中的棋盘，
按连连看规则计算可连接的同值方块对，并模拟鼠标点击自动完成消除。

## 功能特点

- 自动识别 QQ 游戏连连看窗口
- 读取进程内存还原棋盘，按连连看规则寻找可连接的方块对
  - 支持直线、一个拐点、两个拐点连接
  - 支持路径绕棋盘外框一圈（连连看的标准规则）
- 自动点击完成消除
- 检测死局（无可消除对时自动暂停并提示，可能需要洗牌）
- 支持快捷键控制启动/暂停

## 使用要求

- Windows 操作系统
- QQ 游戏大厅
- QQ 连连看游戏窗口（经典模式）

## 编译

使用 Visual Studio 2022（工具集 v143）打开 `link.sln` 直接生成即可。工程已配置：

- C++17（四种配置均已开启 `stdcpp17`）
- `/utf-8` 编译选项（源码为 UTF-8 编码，确保中文窗口标题与控制台输出正确）

> 源文件统一以 UTF-8 存储，仓库通过 `.gitattributes` / `.editorconfig` 固定编码，
> 请勿将 `main.cpp` 另存为 GBK，否则会重新引入窗口标题乱码、找不到窗口的问题。

## 使用方法

1. 启动 QQ 游戏大厅，进入连连看游戏
2. 确保游戏窗口标题为“QQ游戏 - 连连看角色版”
3. 以**管理员身份**运行本程序
4. 使用以下快捷键控制程序：
   - F1：开始自动消除
   - F2：暂停自动消除

## 注意事项

- ！！！ 必须以管理员身份运行 ！！！（否则 `OpenProcess` 会被拒绝，程序会提示）
- 使用前请确保游戏窗口没有被遮挡
- 程序运行时请勿移动游戏窗口位置
- 建议在游戏开始前启动程序

## 已知限制

- **内存地址是固定值**（`START_ADDRESS` / `END_ADDRESS`），仅对特定版本的游戏客户端有效；
  若客户端更新导致棋盘地址变化，需要重新定位并修改这两个常量。
- **点击坐标是标定值**（相对窗口左上角的像素偏移 `CLICK_ORIGIN_*` / `CELL_*`），
  与游戏窗口的边框、标题栏样式相关；不同 Windows 版本/主题或缩放下可能需要重新标定。

## 技术说明

程序通过 `ReadProcessMemory` 读取游戏内存还原棋盘，用带一圈空白外框的占用栅格做连接判定
（直线 / 一拐点 / 两拐点，并支持绕外框），再用 `SetCursorPos` + `mouse_event` 模拟点击。
使用了 Windows API 进行进程间通信和窗口操作。
